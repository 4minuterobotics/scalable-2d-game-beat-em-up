# Success Criteria

- **V1 done when** the founder can build a full beat-em-up stage (sprite sheets → animations → stage with parallax → enemy waves → ending) entirely through the editor, with no source-file edits.
- **V2 ready when** a second, non-founder creator can sign up, upload their assets, publish a game under a slug, and receive a payout based on Stripe revenue.

## Non-goals

- Real-time multiplayer.
- Mobile app (browser-only; mobile browsers are supported via responsive canvas).
- Server-authoritative game logic — games run entirely client-side.
- Asset piracy enforcement beyond Stripe-authenticated download of purchased games.
