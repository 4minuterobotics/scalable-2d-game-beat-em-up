# Users

| Phase | User | Need |
|---|---|---|
| V1 | **Founder (William)** | A fast, data-driven editor replacing the tuning currently done by editing source files. Outputs playable games shipped from this same repo. |
| V2 | **Creator** | Sign up, upload sprite sheets / sounds / stage images, lay out stages, publish their game under a slug on the founder's platform, choose a subscription tier, see earnings. |
| V2 | **Player** | Visit a published game URL, play in a browser with no install, optionally watch ads or pay to unlock. |
| V3 *(deferred)* | **Artist-for-hire** | For V1 + early V2, commissions are handled by the founder personally via email/contact — no in-app marketplace. |
